# 🏦 BankFlow – Banking Management System

BankFlow is a console-based Banking Management System developed in Java using Object-Oriented Programming (OOP) principles.

It simulates basic banking operations such as account creation, deposits, withdrawals, transfers, balance management, and savings account interest calculation.

## 🚀 Features

- 🏦 Create and manage bank accounts
- 💰 Deposit money
- 💸 Withdraw money
- 🔄 Transfer money between accounts
- 📊 Display account information
- 💵 Check current account balance
- 📈 Apply interest to Savings Accounts
- 🔎 Search accounts using account number
- 🧾 Transaction handling
- ⚠️ Basic input and account validation

   javac BankingSystem.java
